## Purpose

Определяет наблюдаемые границы данных между этапами конвейера, чтобы
технически успешный запуск не скрывал отсутствие полезного результата.

## ADDED Requirements

### Requirement: Передача результата между этапами наблюдаема
Система SHALL сохранять в результате каждого этапа число входных и выходных
объектов, достаточное для проверки перехода к следующему этапу.

#### Scenario: Этап не создаёт выходных объектов
- **WHEN** этап обработал входные данные, но создал ноль выходных объектов
- **THEN** результат прогона явно содержит нулевое число выходных объектов и
  машиночитаемую причину этого результата

### Requirement: Сквозная проверка конвейера
Система SHALL иметь детерминированный интеграционный сценарий, который
проводит один валидный материал через BP-1, BP-2, BP-3, BP-4, BP-5 и BP-6.

#### Scenario: Валидный материал проходит конвейер
- **WHEN** выполняется сквозной сценарий с валидным сырым материалом
- **THEN** каждый последующий этап получает ожидаемую входную запись и
  создаёт предусмотренный его контрактом выходной результат
