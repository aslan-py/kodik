## ADDED Requirements

### Requirement: Экран пайплайна показывает журнал работы
Раздел «Пайплайн» SHALL предоставлять отдельный доступный экран «Журнал работы» с текущими и прошлыми событиями конвейера. Экран MUST показывать время, статус/важность, прогон, этап и понятное сообщение без технического шума.

#### Scenario: Администратор следит за текущим запуском
- **WHEN** администратор открывает журнал во время выполнения прогона
- **THEN** он видит новые события запуска и этапов после обновления страницы без необходимости открывать контейнеры или Flower

### Requirement: Журнал позволяет найти причину конкретного результата
Экран журнала SHALL позволять отфильтровать события по прогону, этапу, периоду и уровню важности, а также открыть журнал конкретного прогона из его истории.

#### Scenario: Этап не обработал данные
- **WHEN** администратор открывает журнал завершённого прогона с пустым результатом этапа
- **THEN** он видит сообщение, объясняющее, что данных для обработки не было, а не только технический статус
