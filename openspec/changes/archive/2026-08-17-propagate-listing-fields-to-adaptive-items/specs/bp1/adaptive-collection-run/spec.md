## ADDED Requirements

### Requirement: Элементы сырья несут собственные атрибуты источника, без LLM на каждый элемент

Значения `published_at`, `region` и `media_name`, извлекаемые для элемента
непосредственно с исходной страницы источника селекторами адаптера на
уровне листинга, SHALL попадать в соответствующий элемент сырьевого слоя
вместо системных заглушек. Отсутствие извлечённого значения SHALL
отражаться как `null`, а не подменяться значением, не относящимся к самому
событию (в частности, `media_name` элемента SHALL NOT принимать значение
идентификатора/URL источника в качестве замены отсутствующего имени
публикатора). Заполнение этих полей SHALL NOT требовать отдельного LLM-
вызова на каждый элемент — используются только селекторы адаптера,
сгенерированные один раз на источник и закэшированные.

#### Scenario: Селекторы листинга извлекли атрибуты события

- **WHEN** у адаптера источника заданы рабочие селекторы `published_at`/
  `region`/`media_name` для карточки на странице листинга, и они успешно
  сработали для конкретного элемента
- **THEN** соответствующий элемент сырья содержит извлечённые значения этих
  полей, а не `null`

#### Scenario: Имя публикатора не определено

- **WHEN** селекторы листинга не определили имя публикатора для элемента
- **THEN** `media_name` элемента сырья остаётся `null` и не заменяется
  идентификатором или URL самого источника

#### Scenario: Дата или регион не определены селекторами листинга

- **WHEN** селекторы листинга не определили `published_at` или `region` для
  элемента
- **THEN** соответствующее поле элемента сырья остаётся `null`; система
  SHALL NOT запускать дополнительный LLM-вызов для этого элемента, чтобы
  восполнить отсутствующее значение
