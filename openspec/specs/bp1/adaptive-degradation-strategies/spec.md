# bp1/adaptive-degradation-strategies Specification

## Purpose

Поведение стратегий деградационной лестницы обхода источника
(FAST/CRAWL4AI/BROWSER/WAYBACK/STEALTH/HITL) — в частности, что именно
считается завершённой попыткой получения контента для стратегий,
управляющих настоящим браузером.

## Requirements

### Requirement: JS-рендерящая стратегия дожидается отрисованного контента
Стратегия обхода, управляющая браузером для получения страницы источника
(включая обход антибот-защиты), SHALL дожидаться появления
содержательного контента (результатов, элементов данных) в отрисованной
странице, прежде чем зафиксировать её содержимое как итог попытки — а не
читать содержимое сразу после первичной загрузки документа. Многие
источники (SPA, антибот-защищённые новостные сайты) подгружают
результаты отдельным запросом уже после первичной загрузки — чтение
содержимого сразу после загрузки документа SHALL NOT считаться
достаточным для таких источников.

#### Scenario: Контент подгружается асинхронно после первичной загрузки
- **WHEN** JS-рендерящая стратегия загружает страницу источника, у
  которого искомые данные (например, результаты поиска) отображаются
  отдельным запросом уже после первичной загрузки документа
- **THEN** стратегия дожидается появления этих данных в отрисованной
  странице, прежде чем зафиксировать итоговое содержимое попытки

#### Scenario: Содержательный контент не появляется в разумный срок
- **WHEN** ожидаемые элементы данных не появляются в течение отведённого
  бюджета ожидания
- **THEN** стратегия завершает попытку с тем содержимым отрисованной
  страницы, которое есть на момент истечения ожидания, не блокируясь
  бесконечно

#### Scenario: Данные уже присутствуют сразу после загрузки
- **WHEN** страница источника отдаёт искомые данные уже в первичной
  загрузке документа (без асинхронной подгрузки)
- **THEN** стратегия не тратит полный бюджет ожидания впустую — попытка
  завершается, как только содержательный контент обнаружен
