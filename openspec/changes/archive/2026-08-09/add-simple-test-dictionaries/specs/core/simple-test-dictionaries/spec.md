## Purpose

Узкий, идемпотентный сидер справочников под сквозную ручную проверку пайплайна: один конкурент, один источник, минимальный набор правил фильтрации/маршрутизации, спроектированных под шесть новостей заглушки этапа 1 (`bp1/minimal-pipeline-stub`).

## ADDED Requirements

### Requirement: Скрипт заливает узкий набор справочников под тестовый сценарий
Скрипт ОБЯЗАН заливать ровно: одного конкурента, один источник, один чёрный домен, одно стоп-слово, одно правило лимита антишума, два канала доставки (email, telegram), один тип значимого события, одного тестового пользователя-получателя и одно (или несколько — по числу каналов) правило маршрутизации на этого пользователя.

#### Scenario: Запуск скрипта
- **WHEN** запускается `python -m core.scripts.stages.simple_dictionaries`
- **THEN** перечисленные справочники заполняются согласованным набором, достаточным для проверки всех фильтров BP-2, приоритезации BP-3 и доставки алерта BP-5 без дополнительной ручной правки

### Requirement: Повторный запуск не накапливает дубли
Скрипт ОБЯЗАН при каждом запуске (первом и последующих) сносить ранее залитые им справочники и заливать заново, а не дописывать поверх существующих данных.

#### Scenario: Повторный запуск скрипта
- **WHEN** скрипт запускается повторно поверх уже залитых им данных
- **THEN** старые версии этих справочников удаляются, новые заливаются заново, дублей не остаётся

### Requirement: Согласованность с новостями заглушки этапа 1
Чёрный домен, стоп-слово и правило лимита антишума ОБЯЗАНЫ быть заполнены так, чтобы соответствовать конкретным новостям заглушки этапа 1 (`bp1/minimal-pipeline-stub`) — домен второй новости, фраза из текста третьей новости, домен четвёртой/пятой/шестой новостей.

#### Scenario: Прогон BP-2 после заливки справочников
- **WHEN** после запуска `simple_dictionaries` и заглушки этапа 1 запускается BP-2
- **THEN** вторая новость отклоняется по чёрному домену, третья — по стоп-слову, а из четвёртой/пятой/шестой новостей (общий домен) антишум оставляет ровно одну
