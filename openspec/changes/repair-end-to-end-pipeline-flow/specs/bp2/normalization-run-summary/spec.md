## MODIFIED Requirements

### Requirement: Сводка прогона нормализации
BP-2 SHALL возвращать число обработанных сырых снимков, число извлечённых из
них элементов, число созданных нормализованных строк и разбивку отклонений.
При нулевом числе строк сводка SHALL различать пустые входные `items` и
отклонение всех извлечённых элементов.

#### Scenario: Сырой снимок содержит пустой список материалов
- **WHEN** BP-2 обрабатывает один или более `RawItem` с пустым `items`
- **THEN** сводка показывает число таких снимков и причину нулевого результата
  `empty_raw_items`

#### Scenario: Все извлечённые элементы отклонены
- **WHEN** BP-2 извлёк элементы, но фильтры отклонили каждый из них
- **THEN** сводка показывает число извлечённых элементов и причины отклонения
