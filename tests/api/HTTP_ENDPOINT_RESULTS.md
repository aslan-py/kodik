# Результаты проверки HTTP endpoints

Классификация падений при реализации `verify-and-stabilize-api-endpoints`:

- Тестовые данные: домен `example.test` отклонялся `EmailStr`; заменён на
  валидный `example.com` в HTTP-фикстурах.
- Тестовая транзакция: сценарий после ожидаемого `IntegrityError` нельзя
  продолжать в той же no-commit транзакции; проверки `409` изолированы в
  отдельных тестах.
- Production-код: `AlertRead.event_type_id` ошибочно требовал `int`, хотя
  модель и миграция допускают `NULL` для правил только по приоритету.
  Исправлено на `int | None`, добавлен HTTP-регрессионный сценарий.
- Manifest/OpenAPI: расхождений методов, путей и operationId не обнаружено.
- Несовместимых изменений URL, методов, ролей или схем не потребовалось.

Итоговая проверка:

- опубликовано и покрыто manifest-тестами: 91 из 91 операции;
- `pytest tests/api` на заполненной БД: 271 passed, 1 skipped;
- `pytest tests/api` на чистой мигрированной временной БД: 271 passed,
  1 skipped; временная БД удалена;
- полный `pytest`: 725 passed, 1 skipped;
- Ruff, форматирование и `git diff --check`: успешно;
- реальных сетевых отправок не выполнялось: почтовая граница API заменена
  `AsyncMock`, остальные HTTP-тесты работают через ASGI transport без порта.

Единственный skip относится к проверке конфликта `topic_limit`: у таблицы
нет ограничения уникальности, поэтому ответ `409` для дубликата к её
контракту не относится.
