## Purpose

Позволяет LLM-этапу категоризации (BP-3) прикрепить к размеченному событию список конкретных задач, чтобы эти данные не терялись и были доступны для дальнейшего использования (например, для плана действий BP-6 в будущем изменении).

## ADDED Requirements

### Requirement: Размеченное событие хранит список задач от LLM
`CategorizedEvent` ОБЯЗАНА иметь поле `task`, способное хранить ноль или более строк-задач, сформированных LLM-этапом категоризации для этой же новости.

#### Scenario: LLM сформировала задачи для новости
- **WHEN** BP-3 категоризирует нормализованный объект, и LLM-шаг генерации задач вернул непустой список задач для id этого объекта
- **THEN** сохранённое размеченное событие содержит `task`, заполненный ровно этим списком, в том же порядке, в котором его вернула LLM

#### Scenario: LLM не сформировала задач
- **WHEN** LLM-шаг генерации задач не вернул запись (или вернул пустой список) для id новости
- **THEN** поле `task` сохранённого события пустое или отсутствует, и сохранение события не завершается ошибкой

### Requirement: Список задач сохраняется вместе с остальной разметкой
Сохранение размеченного события ОБЯЗАНО записывать список `task` в той же операции записи, что и остальные поля от LLM (приоритет, категория, тональность, комментарий, требуемое действие, отдел, срок, медиаиндекс), а не отдельным шагом.

#### Scenario: Список задач сохраняется вместе с категоризацией
- **WHEN** шаг сохранения BP-3 создаёт новую строку `CategorizedEvent` для нормализованного объекта, у которого есть и данные категоризации, и сформированные задачи
- **THEN** строка создаётся с одновременно заполненными и полями категоризации, и полем `task`, одной вставкой
