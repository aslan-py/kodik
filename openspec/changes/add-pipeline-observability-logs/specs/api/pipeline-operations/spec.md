## ADDED Requirements

### Requirement: API предоставляет журнал событий конвейера
API SHALL предоставлять авторизованным пользователям постраничный список событий конвейера и события конкретного прогона. Каждая запись MUST включать идентификатор, время, уровень, понятное сообщение, идентификатор прогона и номер этапа при наличии.

#### Scenario: Получение общего журнала
- **WHEN** пользователь с правом просмотра запрашивает журнал с фильтрами периода, прогона, этапа или уровня
- **THEN** API возвращает события от новых к старым и метаданные пагинации

#### Scenario: Получение журнала конкретного прогона
- **WHEN** пользователь запрашивает события существующего прогона
- **THEN** API возвращает только связанные с ним события в хронологическом порядке
