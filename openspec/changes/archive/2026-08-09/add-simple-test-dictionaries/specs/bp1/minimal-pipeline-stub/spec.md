## MODIFIED Requirements

### Requirement: Заглушка этапа 1 заливает минимальный набор
Заглушка этапа 1 конвейера ОБЯЗАНА при каждом запуске заливать фиксированный минимальный набор: один конкурент, один снимок (`raw_item`), шесть новостей со спроектированными исходами по фильтрам BP-2 — две доходят до `status=ok` в `normalized_item` (пригодны для дальнейшей категоризации BP-3), четыре отклоняются разными механизмами отсева (чёрный домен, стоп-слово, антишум по повторяющемуся домену).

#### Scenario: Запуск заглушки этапа 1
- **WHEN** запрошен запуск этапа 1 (по кнопке в админке, через CLI или как часть `run_all()`)
- **THEN** в `raw_item` появляется ровно один новый снимок на одного конкурента с шестью новостями, который после прогона BP-2 (при заполненных чёрном домене/стоп-слове/лимите антишума под эти новости) даёт ровно две строки со `status=ok` в `normalized_item`
