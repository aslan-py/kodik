## MODIFIED Requirements

### Requirement: Прогон сбора по активным задачам
Прогон сбора SHALL обходить только активные задачи сбора и сохранять результат
в сырьевой слой в формате, который принимает нормализация BP-2. Задача
считается активной, только если активны одновременно она сама, её источник и
её конкурент. Содержательный результат и пустой результат SHALL быть
различимы в сводке прогона и сохранённом сыром результате.

#### Scenario: Прогон при наличии активных задач
- **WHEN** запущен прогон сбора и в системе есть хотя бы одна полностью
  активная задача сбора
- **THEN** по каждой такой задаче выполняется обход источника, результат
  сохраняется в сырьевой слой, а сводка показывает число задач, найденных
  материалов и пустых результатов

#### Scenario: Источник не содержит материалов
- **WHEN** обход источника завершился без извлечённых материалов
- **THEN** результат помечается как пустой с причиной, а не выдаётся за
  содержательный успешный снимок

#### Scenario: Задача выключена на любом уровне
- **WHEN** запущен прогон сбора, а у задачи выключена она сама, её источник
  или её конкурент
- **THEN** задача пропускается без обращения к источнику, а причина пропуска
  отражается в сводке прогона

### Requirement: TLS-проверка поддерживаемых источников
HTTP-стратегии SHALL сохранять проверку TLS-сертификата и использовать
доверенные корневые сертификаты, поставляемые с образом приложения, для
поддерживаемых источников.

#### Scenario: Источник использует поддерживаемый национальный УЦ
- **WHEN** источник отдаёт сертификат от доверенного корня, отсутствующего в
  стандартном системном наборе
- **THEN** сбор в контейнере проходит TLS-проверку без отключения верификации
  сертификата для произвольных доменов
