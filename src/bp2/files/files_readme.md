# Что за папка
- Тут лежит JSON скаченный https://github.com/pensnarik/russian-cities - список городов и регионов РФ.
Так как города не меняются часто, этот список используем для создания справочника Region
В дальнейшем можно будет сделать парсер для обновения данных из официальных исчтоников(что правильнее) , либо корректировать города и регионы по мере необходимости через админку
