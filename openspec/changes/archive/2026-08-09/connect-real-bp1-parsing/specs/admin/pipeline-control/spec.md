## MODIFIED Requirements

### Requirement: Переключатель пересборки у этапа, который её поддерживает
Рядом с элементом управления этапа, поддерживающего режим пересборки, админ-панель SHALL предоставлять переключатель, включающий этот режим для конкретного запуска.

#### Scenario: Запуск с включённой пересборкой
- **WHEN** пользователь включает переключатель пересборки и нажимает элемент управления этапа
- **THEN** этот этап выполняется в режиме пересборки (уже обработанные данные пересматриваются новыми правилами, без повторного сбора исходных)

#### Scenario: Запуск без пересборки
- **WHEN** пользователь нажимает элемент управления этапа, не включая переключатель пересборки
- **THEN** этап выполняется в обычном режиме, как и раньше

## ADDED Requirements

### Requirement: Переключатель выбора реализации у этапа с несколькими реализациями
Рядом с элементом управления этапа, у которого есть и настоящая реализация, и заглушка, админ-панель SHALL предоставлять переключатель выбора реализации для конкретного запуска. Положение переключателя по умолчанию SHALL соответствовать настройке приложения, чтобы нажатие кнопки без изменения переключателя давало то же поведение, что запуск этапа из CLI или по расписанию.

#### Scenario: Запуск с переключателем в положении по умолчанию
- **WHEN** пользователь нажимает элемент управления этапа, не трогая переключатель реализации
- **THEN** выполняется реализация, заданная настройкой приложения, и пользователю показывается результат прогона

#### Scenario: Разовый выбор другой реализации
- **WHEN** пользователь переводит переключатель реализации в положение, отличное от настройки, и нажимает элемент управления этапа
- **THEN** выполняется выбранная реализация, а настройка приложения остаётся прежней и следующий запуск из CLI или по расписанию снова использует её

#### Scenario: Результат показывает, какая реализация отработала
- **WHEN** этап с несколькими реализациями выполнен из админки
- **THEN** в показанном результате видно, была выполнена заглушка или настоящая реализация
