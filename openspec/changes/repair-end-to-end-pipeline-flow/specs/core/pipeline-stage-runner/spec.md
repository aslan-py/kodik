## ADDED Requirements

### Requirement: История этапа содержит диагностическую сводку
Для завершённого этапа история конвейера SHALL сохранять и возвращать полный
результат этапа, включая счётчики входа, выхода и причину нулевого выхода.

#### Scenario: Администратор проверяет успешный этап без результата
- **WHEN** этап завершился технически успешно, но создал ноль выходных данных
- **THEN** история прогона позволяет определить этот факт и его причину без
  чтения логов воркера или JSON в базе данных
