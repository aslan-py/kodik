## ADDED Requirements

### Requirement: Оркестратор пишет контекст прогона в stdout
При постановке, старте, завершении, ошибке или пропуске прогона оркестратор SHALL писать структурированную строку в stdout. Строка MUST содержать `pipeline_event`, `run_id` при наличии, статус, номер этапа и Celery task id при наличии.

#### Scenario: Этап завершается
- **WHEN** worker завершает этап
- **THEN** stdout содержит событие с `run_id`, номером этапа, итоговым статусом и краткой безопасной сводкой результата

#### Scenario: Плановый запуск пропущен
- **WHEN** Beat не создаёт запуск из-за активного прогона
- **THEN** stdout содержит событие пропуска и `run_id` активного прогона
