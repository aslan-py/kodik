# core/pipeline-stage-runner Specification

## Purpose

Ручной запуск любого этапа конвейера BP-1…BP-7 по отдельности или всех подряд, без Celery, с проверкой готовности данных перед запуском и понятным сводным отчётом по прогону.

## Requirements

### Requirement: Запуск одного этапа по номеру
Система SHALL позволять запустить ровно один этап конвейера (1–7) по его номеру независимо от остальных этапов. Этап MAY поддерживать альтернативный режим запуска (пересборка уже обработанных данных новыми правилами, без повторного сбора исходных данных) — запросить этот режим SHALL быть возможно явно, отдельно от обычного запуска.

#### Scenario: Запуск существующего этапа
- **WHEN** запрошен запуск этапа с номером, для которого есть реализация или заглушка
- **THEN** выполняется логика этого этапа и возвращается результат прогона (сколько строк обработано/создано)

#### Scenario: Запуск несуществующего номера этапа
- **WHEN** запрошен запуск этапа с номером вне диапазона 1–7
- **THEN** запуск не начинается, и возвращается понятная ошибка с указанием, что такого этапа нет

#### Scenario: Запрошена пересборка у этапа, который её поддерживает
- **WHEN** запрошен запуск этапа в режиме пересборки, и этот этап поддерживает такой режим
- **THEN** выполняется пересборка уже обработанных данных этого этапа новыми правилами, без повторного сбора исходных данных

#### Scenario: Запрошена пересборка у этапа, который её не поддерживает
- **WHEN** запрошен запуск этапа в режиме пересборки, а этот этап такого режима не поддерживает
- **THEN** запуск не начинается, и возвращается понятная ошибка с указанием, что у этого этапа нет режима пересборки

### Requirement: Проверка готовности данных перед запуском этапа
Перед выполнением этапа, для которого требуются данные предыдущего слоя, система SHALL проверить, что эти данные существуют, и не запускать этап, если их нет.

#### Scenario: Данных предыдущего слоя нет
- **WHEN** запрошен запуск этапа N, а таблица данных, которую производит этап N−1, пуста
- **THEN** этап N не выполняется, и возвращается понятная ошибка, указывающая, каких данных не хватает и какой этап должен быть прогнан раньше

#### Scenario: Данные предыдущего слоя есть
- **WHEN** запрошен запуск этапа N, а таблица данных этапа N−1 содержит хотя бы одну подходящую строку
- **THEN** этап N выполняется

#### Scenario: Первый этап конвейера не требует предусловий
- **WHEN** запрошен запуск самого первого этапа конвейера
- **THEN** проверка предыдущего слоя не выполняется, этап запускается напрямую

#### Scenario: Перенос кандидатов в источники не требует новых кандидатов
- **WHEN** запрошен запуск этапа переноса кандидатов-источников, а очередь кандидатов на перенос пуста
- **THEN** этап выполняется и завершается успешно с нулевым результатом переноса, это не считается ошибкой предусловия

### Requirement: Запуск всего конвейера одной командой
Система SHALL позволять запустить все этапы конвейера подряд одной командой, при этом сбой или ошибка предусловия одного этапа НЕ SHALL прерывать выполнение остальных этапов.

#### Scenario: Один из этапов завершается ошибкой
- **WHEN** запущен весь конвейер, и один из этапов завершается ошибкой (исключением или незалуженным предусловием)
- **THEN** система переходит к следующему этапу по порядку и продолжает выполнение оставшихся этапов

#### Scenario: Итоговая сводка по прогону всего конвейера
- **WHEN** прогон всех этапов конвейера завершён (успешно или с ошибками на части этапов)
- **THEN** возвращается сводка по каждому из семи этапов: выполнен успешно, завершился ошибкой (с кратким описанием), или не был затронут

### Requirement: Временные заглушки помечены явно
Этап конвейера, реализация которого временно заменена заглушкой (демо-данными вместо реальной бизнес-логики), SHALL быть отмечен как временный в результате запуска этого этапа и в сводке по всему конвейеру.

#### Scenario: Результат запуска заглушечного этапа
- **WHEN** запускается этап, чья реализация на момент запуска является временной заглушкой
- **THEN** результат запуска (и, если это часть прогона всего конвейера, сводка) явно показывает, что этот этап выполнен заглушкой, а не финальной реализацией
