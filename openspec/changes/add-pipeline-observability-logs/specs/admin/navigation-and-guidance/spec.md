## ADDED Requirements

### Requirement: Технический журнал доступен из раздела «Пайплайн»
Административная панель SHALL давать понятный переход из раздела «Пайплайн» во внешний журнал Grafana, не создавая в панели отдельный журнал или модель данных.

#### Scenario: Администратор ищет технические детали прогона
- **WHEN** администратор открывает раздел «Пайплайн»
- **THEN** он видит действие «Технические логи (Grafana)» и получает адрес журнала
