# Что за папка

Данные, из которых скрипты `core/scripts` заполняют базу. Кода тут нет —
только файлы, которые правятся руками.

## `cities.json`

JSON, скаченный с https://github.com/pensnarik/russian-cities — список городов
и регионов РФ. Так как города не меняются часто, этот список используем для
создания справочника `Region`.

В дальнейшем можно будет сделать парсер для обновления данных из официальных
источников (что правильнее), либо корректировать города и регионы по мере
необходимости через админку.

Читает: `core/scripts/stages/dictionaries.py`.

## `news_dataset.csv`

Демо-новости конвейера — один источник контента сразу для трёх этапов:
BP-1 берёт из строки сырьё (и «пачкает» его перед укладкой), BP-2 — те же
поля начисто, BP-3 — разметку. Разделитель `;`, кодировка UTF-8.

| Колонка | Что в ней |
|---------|-----------|
| `id` | Номер строки. По нему на новость ссылаются снимки в `stages/bp1.py` |
| `competitor` | Имя конкурента; из этой колонки строится справочник `competitor` |
| `region` | Каноническое имя города (пусто = регион не определён) |
| `published_at` | Дата публикации, ISO |
| `media_name` | Человекочитаемое имя СМИ |
| `url` | Ссылка на публикацию, из неё выводится `media_domain` |
| `title`, `text` | Заголовок и текст **начисто** — как их должен отдать BP-2 |
| `category` | Имя категории из справочника `category` |
| `priority` | `p1` / `p2` / `p3` |
| `tonality` | `positive` / `neutral` / `negative` |
| `department` | Ответственный отдел |
| `action` | Что делаем по событию (пусто = действие не требуется) |
| `comment` | Вывод аналитика одной строкой |
| `reject` | Пусто = чистое событие; иначе причина отсева в BP-2 |

Колонки блока BP-3 (`category`…`comment`) заполнены только у чистых событий:
отбракованное фильтрами до LLM не доходит. Исключение — `reject=noise_limit`:
событие нормальное, его вытеснил лимит антишума, разметка у него остаётся.

### Как добавить новость в демо

1. Дописать строку в CSV (id = следующий по порядку).
2. Упомянуть этот id в снимке `SNAPSHOTS` (`core/scripts/stages/bp1.py`) —
   у снимка того же конкурента.
3. Пересобрать данные: `python -m core.scripts.seed_all`.

Больше править нечего: справочник конкурентов, сырьё, факты и разметка
соберутся из этой же строки.
