## 2. Повторный запуск: что произойдёт с уже обработанными новостями

- [x] 2.1 Добавить в `src/bp3/README.md` раздел, описывающий поведение при повторном запуске конвейера: LLM обрабатывает только `normalized_item` со `status='ok'`, у которых ЕЩЁ НЕТ строки в `categorized_event` (проверка `NOT EXISTS`, `src/bp3/fetch_data.py::fetch_data`) — уже категоризированные новости повторно через LLM не гоняются, токены на них не тратятся, дублей в `categorized_event` не возникает (там `UNIQUE` на `normalized_item_id`)
