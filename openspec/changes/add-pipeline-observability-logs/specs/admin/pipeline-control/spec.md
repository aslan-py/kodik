## ADDED Requirements

### Requirement: Управление конвейером даёт доступ к Grafana
Раздел «Пайплайн» SHALL содержать действие, возвращающее настроенный адрес Grafana и краткую подсказку по поиску прогона. Действие MUST NOT проксировать или сохранять логи через API приложения.

#### Scenario: Администратор открывает технические логи
- **WHEN** администратор запускает действие технических логов
- **THEN** панель показывает адрес Grafana и подсказку поиска по `run_id`
