- [x] 4.7 Баг найден пользователем в реальном браузере (не через curl/API, где 4.1–4.6 проверялись изначально): переключатель «пересобрать» либо срабатывал без нажатия, либо не реагировал вовсе. Причина — двойная:
  1. Использован не тот механизм: `widget_action_filters` — для Chart-виджетов (фильтрация данных графика), а не для полей ввода Action-виджета. Нужно `widget_action_props.arguments` — см. `find_action_widget.py`/`find_WLe.py` разбор `index.min.js`.
  2. Даже после этого `WidgetType.Checkbox` не работал: в FastAdmin 0.10.0 общий `onChange` Action-формы ожидает готовое значение (`onChange(value)`, как у `Switch`), а Antd `Checkbox` передаёт туда событие (`onChange(event)`, булево — в `event.target.checked`) — для него отдельного разбора в библиотеке нет, в состояние попадает объект события вместо `true`/`false`.

  Исправлено: `widget_action_props=WidgetActionProps(arguments=[...])` с `WidgetType.Switch` вместо `Checkbox`; поле переименовано в `'пересобрать'` (подпись берётся из технического имени, `widget_props.label` не работает для произвольных полей). Проверено через прямой HTTP `POST /admin/api/widget-action/...` под реальной авторизованной сессией пользователя — `value=false` и `value=true` дают разный результат (`raw_items: 0` vs `raw_items: 1`), переключатель реально влияет на поведение. Визуально в браузере пользователь подтвердил, что переключатель появился и (после фикса) не проверен повторно — см. 5.1.
