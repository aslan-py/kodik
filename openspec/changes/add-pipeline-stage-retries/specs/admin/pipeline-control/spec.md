## ADDED Requirements

### Requirement: История прогона показывает ожидающий повтор этап
История конвейерного прогона в API и админ-панели SHALL показывать для этапа, ожидающего автоматического повтора, его состояние, номер выполненной попытки, допустимое общее число попыток, последнюю причину ошибки и запланированное время следующей попытки. Пока хотя бы один этап ожидает повтор, прогон SHALL отображаться активным.

#### Scenario: Просмотр этапа после временной ошибки
- **WHEN** временная ошибка этапа поставила его в ожидание автоматического повтора
- **THEN** пользователь видит, что этап ожидает повтор, номер текущей попытки, причину последней ошибки и точное время следующей попытки

#### Scenario: Просмотр этапа после исчерпания повторов
- **WHEN** временная ошибка исчерпала лимит дополнительных попыток
- **THEN** пользователь видит окончательный ошибочный статус этапа, число выполненных попыток и последнюю причину ошибки, без времени следующей попытки
